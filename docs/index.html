The 11 AI agents

A team coordinated by a LangGraph supervisor. Each has one job.

🧭 Boss

LangGraph supervisor. Checks my START/STOP switch, runs the team.

🔍 Scout

Searches LinkedIn, Indeed, Internshala. Stores new jobs.

⚖️ Judge

Grades each job A–F using RAG evidence from my resume; flags scams.

✂️ Tailor

ATS-scores jobs, suggests resume edits — for my approval.

📮 Applier

Routes Grade-A jobs into apply / outreach lanes.

📧 Outreach

Drafts personalized HR emails from my real experience.

📊 Tracker

Reads Gmail to catch interview invites & rejections.

🎤 Interview-Prep

Company briefs, mock Qs, feedback, concept coach.

🤝 Referral Finder

Drafts referral messages + the LinkedIn search.

🧠 Coding Coach

Tracks LeetCode, names what to solve next by level.

✉️ Notifier

Emails me the best jobs each day.

Inside the full app (13 pages)

The interactive dashboard runs locally (needs secret keys, so it can't live on a public page).

🎛️ Command Center + Today's Jobs

One START/STOP switch; jobs ranked, by date, source, resume type.

💬 AI Interviewer + 🎙️ Live Voice Interview

Chat or a Zoom-like voice interview that talks back.

🎥 Video Mock Interview

Camera + speech-to-text + AI feedback on answers.

📈 Grow & Practice

LeetCode coach with streaks + company-specific plans.

📄 My Resumes

Upload unlimited named resumes; each matches its own jobs.

🏁 Tracker + 📧 Outreach Book

Round-by-round tracking; approve HR emails before sending.

Run the full interactive app: clone the repo, then double-click START_WEBSITE.bat (or cd web && python manage.py runserver) and open localhost:8010. Built with Python · LangGraph · Supabase/pgvector (RAG) · Gemini + Groq · Django.
